C AKTIVITAS 1: EKSPERIMEN 10 + 20

Prediksi hasil sebelum menjalankan kode. Jalankan kode dan amati. Simpan file sebagai lkpd_string_number_nama.js.

let b = "20";

Karena nilai variabel a dan b diapit tanda petik (" "), sehingga dianggap sebagai tipe data String. Operator + pada String berfungsi untuk menggabungkan teks (konkatenasi), bukan penjumlahan matematika.
Tidak, keduanya bertipe String.
Ya, benar. Saat dijalankan dengan Node.js/Console Browser, hasilnya adalah 1020 karena JavaScript melakukan penggabungan string.

D AKTIVITAS 2: MENEMUKAN TIPE DATA

Jalankan kode berikut:

let nama = "Asep";
let umur = 16;
console.log(typeof nama);
console.log(typeof umur);
Variabel Prediksi Hasil typeof Kesimpulan
nama Teks / String string Teks di dalam petik adalah String
umur Angka / Number number Angka tanpa petik adalah Number
String adalah tipe data berupa teks yang ditulis menggunakan tanda petik, jika dijumlahkan akan digabungkan. Number adalah tipe data berupa angka tanpa tanda petik yang dapat digunakan langsung untuk operasi aritmatika (seperti penjumlahan, pengurangan, perkalian).

H THINK PAIR SHARE

Pertanyaan Jawaban
Mengapa prompt() perlu dikonversi jika hasilnya ingin dihitung? Karena fungsi prompt() selalu mengembalikan input dalam bentuk String. Jika tidak dikonversi, operasi penjumlahan + akan melakukan penggabungan teks, bukan penjumlahan angka.
Apa perbedaan "10" dengan 10? "10" adalah tipe data String (teks angka), sedangkan 10 adalah tipe data Number (nilai numerik asli).
Apa yang terjadi jika lupa menggunakan Number()? Penjumlahan variabel akan menghasilkan gabungan string (misal: "10" + "20" = "1020"), yang menyebabkan perhitungan matematis salah.
Jawaban kami secara umum sama pada konsep dasar, namun teman saya menuliskan penjelasan yang lebih singkat. Perbedaan ini terjadi karena sudut pandang penjelasan saat menganalisis program.
Temuan penting: "Setiap input dari user melalui browser (seperti prompt) secara default bertipe String, sehingga harus selalu dikonversi ke Number sebelum diproses secara matematis."
